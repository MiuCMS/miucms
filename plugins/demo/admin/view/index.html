建议按这个顺序体验
1. 配置插件

进入“插件配置”填写站点名和欢迎语。密码字段不会回显；留空保存表示保留旧值。

2. 查看前台

打开前台演示页，观察配置读取和 {demo:hello} 标签的输出。

3. 触发文档钩子

发布一篇文档，documentAdded() 会将标题写入插件自己的数据表。

4. 阅读源码

从 Plugin.php 开始，再看菜单、控制器、视图、路由、标签和 SQL 文件。

这个插件演示了什么
  • getConfigFields()：text、textarea、switch、number、radio、select、password、help_area、条件显示。
  • PluginAdminBase：后台登录校验、插件视图渲染和配置读取。
  • 自动钩子：templateParse()、documentAdded()、userLogin()。
  • 映射钩子：hooks.php 将 search_before 指向 onSearchBefore()。
  • 前台路由：route.php → 控制器 → 独立模板。
  • 模板标签：参数通过 var_export() 安全写入编译代码，输出时做 HTML 转义。
  • 数据表：安装脚本使用 __PREFIX__，只创建插件自己的表。
  • 配置中的示例 API Key 仅演示密码字段，不会调用服务，也不会显示明文。
