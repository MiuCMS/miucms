模板标签示例

下面的文字由插件标签 {demo:hello name='访客' /} 生成：

{demo:hello name='访客' /}

标签类：plugins/demo/taglib/Demo.php。安装并启用插件后，插件标签库会自动加载。

从页面反查代码

  • 路由定义：plugins/demo/route.php
  • 前台控制器：plugins/demo/controller/Index.php
  • 当前模板：plugins/demo/view/hello.html
  • 配置定义：plugins/demo/Plugin.php::getConfigFields()
  • 页脚注入：Plugin.php::templateParse()，默认关闭。
  • 文档记录：Plugin.php::documentAdded() 写入本插件的 demo_record 表。

插件配置中的 API Key 仅演示密码字段，本页面不会读取或显示它。
