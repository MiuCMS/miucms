自动定时任务定时生成sitemap
/**
 * 生成 sitemap 地图文件
 *
 * 用法：
 *   php think sitemap                按后台「SEO → Sitemap」勾选的地图类型生成
 *   php think sitemap --type=all     强制生成 xml / txt / html / llms 四种地图
 *   php think sitemap --type=llms    只生成 llms.txt（也可指定 xml / txt / html）
 *
 * 建议挂定时任务（比如每小时一次）
 */
自动定时任务定时提交到百度搜索资源平台
/**
 * 百度普通收录（API 推送）
 *
 * 用法：
 *   php think baidu-push                       推送最新的一批文档（数量取后台「生成数量」）
 *   php think baidu-push --num=10              推送最新 10 篇
 *
 * 建议挂定时任务（比如每天一次）
 * 注意：百度普通收录接口每天有配额（一般个人站 10~100 条/天），
 * 返回里会带今日剩余条数，别把 --num 设太大浪费配额。
 */

新增/修改文档/栏目时，地图会同步更新

xml地图文件使用，你输入的网站的网页内容更新的频率。

xml地图文件使用，所抓取页面在您网站的重要性，告诉搜索引擎抓取的优先级。数值越大，优先级越高。

文档  篇     TAG  篇

文档加TAG数量不能超过5000条；数值大对更新文档速度有影响

开启后，发布或编辑文档时会自动将文档地址推送到百度搜索资源平台；请填写下方 token，未配置时会跳过推送。

在百度搜索资源平台获取 token 并填入；也可以执行 php think baidu-push 手动或定时推送。
